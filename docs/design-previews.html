B. Security print

Bank cheques carry fine linework and printed marks so that forgeries can be caught. Phishing is forgery too, so here the page itself is a cheque being examined.

  • Aubergine ink #2E0F3E
  • Cheque paper #F8E4ED
  • Security rose #C4346F
  • Stamp rose #A31F55

Fonts: Rozha One for headings, Mukta for text. Both come from Indian type designers.

Why this link was flagged

  • Hyphen in the domain name
  • Extra subdomains before the real name
  • No HTTPS
