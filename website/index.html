About the project

CyberShield AI is a phishing detection and threat intelligence platform. It uses machine learning to study the features of a website and classify it as legitimate or phishing.

Along with the result, it gives a threat score and shows which features most affected the decision, so a person can understand the warning as well as read it.

The problem

A phishing website copies a trusted site to trick people into giving away passwords or personal details. As more of daily life moves online, these attacks have become a major cybersecurity threat.

Traditional methods rely on blacklists and fixed rules. They often miss new or carefully made phishing sites, because a site cannot be blocked until it is known. Machine learning can judge a site by its features, including sites it has never seen before.

How it works

Checking a website

  1. Step 1Website linkA person enters the link they are unsure about.
  2. Step 2Feature extractionThe system reads 10 features of the link, such as its length, hyphens and use of HTTPS.
  3. Step 3XGBoost modelThe model compares these features with patterns it learned in training.
  4. Step 4Known website checkThe site is checked against 100,000 known websites, and for signs such as an imitated brand name or a short link.
  5. Step 5Result and reasonsThe higher of the two scores is shown, with the reasons in plain words.

Building the model

  1. Step 1Public dataset11,055 website records from the UCI phishing websites dataset, with 30 features each.
  2. Step 2Split the data8,844 records for training and 2,211 held back for testing.
  3. Step 3Compare three modelsRandom Forest, Support Vector Machine and XGBoost, using all 30 features.
  4. Step 4Retrain for live useXGBoost is retrained on the 10 features that can be read from a link alone.
  5. Step 5Store every scanSpring Boot saves each result in PostgreSQL for the history and dashboard.

False alarms are legitimate websites wrongly marked as phishing. The 30-feature models also use details from the web page itself, which the live scanner does not read, so its score is lower. These figures come from dataset records and do not include the warning sign rules.

Only known websites are treated as safe, so a real site outside the list is flagged because it cannot be confirmed. Phishing placed on a known website can pass. It is a first check, not a complete defence.
